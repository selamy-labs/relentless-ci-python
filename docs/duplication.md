# Python duplication gate

The required full local command and Linux analysis jobs run `python -m quality.duplication_main` from the protected check registry. Mise locks the standalone native jscpd 5.3.3 release and its checksums for Linux x64, macOS arm64/x64 and Windows x64. The gate checks the exact version before scanning. Tool absence, installation failure, timeout or a nonzero scanner exit fails verification.

The checker independently discovers every authored `.py` file under `src`, `tests` and `quality`, including nested tests and never-imported verifier modules. It rejects inline jscpd ignore markers, freezes each file's UTF-8 bytes and stages exact copies outside the checkout. A low-threshold native scan of every staged file establishes its path, byte count, format, lines and tokens. The combined scan then requires zero clones of at least 50 tokens spanning five inclusive lines (`--min-lines 4` in this pinned scanner). It disables Git ignore and inherited scanner config, uses one worker, and does not silently ignore oversized files. Narrow generated-root exemptions are defined in [source-scope.md](source-scope.md); there are no duplication-specific source or test exclusions.

The validator checks the native combined report's zero-clone statuses, complete eligible file and folder identities, metrics and totals against the per-file receipts. It rereads the authored inputs after scanning. Reports from earlier runs are removed before the scan; only a fully validated run writes `.quality-results/duplication/verified.json`. Fix a real clone by extracting genuinely shared behavior or by making tests express distinct behavior, without weakening the scope or threshold. A proposed equivalent-clone exception requires separate protected policy rationale and independent maintainer review; none is currently enrolled.

The test suite probes the pinned native tool at both exact boundaries: four identical source lines at 85 tokens pass, five lines at 85 tokens fail, five lines at 49 tokens pass, and five lines at 50 tokens fail. The native scanner emits an empty format inventory when no file reaches the threshold; that clean report is accepted only when the independently checked eligible inventory is also empty. Other probes cover missing reports, wrong version, symlinked report locations, stale receipts, incomplete source inventories, inline suppression, malformed counts and whole-scan expiry. Full Linux analysis runs this gate on every declared Python version; raw native reports must be retained and audited for publication evidence.
